CORE FLOW

一条完整的主链路

从定位进入，到支付、师傅接单、服务完成与评价。未登录用户可以浏览服务，下单时再完成登录与手机号授权。

01 · 入口

定位 / 城市 / 首页

定位授权 → 城市选择 → 搜索 / 分类 → 服务列表

02 · 选购

服务详情 / 师傅

选规格、数量、师傅；可查看师傅资质与评价

03 · 下单

地址 / 时间 / 手机号

选地址 → 选时段 → 手机号授权/验证 → 协议 → 提交

04 · 支付

收银台 / 支付成功

微信支付模拟 → 待接单 → 匹配or指定师傅接单

05 · 履约

订单状态 / 售后

出发 → 服务中 → 完成 → 评价；改期/取消/客服

订单状态机 待付款→ 待接单→ 待服务→ 师傅已出发→ 服务中→ 待评价→ 已完成 ｜ 已取消 / 退款
