# 净到家 · 设计系统

## 1. 品牌概念

- **名称**：净到家
- **Slogan**：专业清洗，安心到家
- **气质**：可信、清爽、有温度；避免冷冰冰的工具感。
- **Logo**：珊瑚红圆角方块 + 白色水滴 + 房屋图形，表达「清洁 + 到家」。全部为原创内联 SVG。
- **插画**：扁平、圆润、低饱和暖色；服务物件 + 气泡/光点，统一视觉语言，不使用照片或外部素材。

## 2. 色彩

| Token | 色值 | 用途 |
|---|---|---|
| `--brand` | `#ff4d4c` | 主品牌色、主按钮、价格、强调 |
| `--brand-strong` | `#e63d3c` | 小字号价格/链接、文字对比 |
| `--brand-soft` | `#fff0ee` | 选中背景、标签、淡色块 |
| `--ink` | `#20293a` | 主文字、标题 |
| `--ink-2` | `#4d5a6e` | 次级文字 |
| `--muted` | `#8a94a6` | 辅助信息、说明 |
| `--mint` | `#16a98f` | 成功、环保清洁、服务保障 |
| `--gold` | `#f5a623` | 优惠券、提醒 |
| `--blue` | `#3f7be0` | 信息、待接单、隐私 |
| `--purple` | `#8668dd` | 待评价、会员 |
| `--bg` | `#f5f6f8` | 页面底色 |
| `--card` | `#ffffff` | 卡片 |
| `--cream` | `#fffaf5` | 活动/登录/协议提示底 |

规则：

- 主色用于**一个页面一个主行动**；次要操作使用描边/灰底；
- 价格、优惠、选中态统一使用珊瑚红，避免多色强调；
- 大面积深色只用于「收银台金额卡」「服务保障/会员卡」「深色活动 Banner」；
- 文字对比：小字号红字使用 `--brand-strong`，避免 `#ff4d4c` 在白底上的对比不足。

## 3. 字体与字号

- 字体：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif`
- 不使用 Inter、不使用衬线体；数字使用 `font-variant-numeric: tabular-nums`。

| 层级 | 字号 | 字重 | 场景 |
|---|---|---|---|
| 页面大标题 | 25–28px | 800–850 | 城市名、分类标题、状态标题 |
| 模块标题 | 16–18px | 750–800 | Section |
| 卡片标题 | 13–15px | 650–750 | 服务名、师傅名 |
| 正文 | 11–12.5px | 400–500 | 描述、说明 |
| 辅助 | 8–10px | 400–600 | 标签、时间、细则 |
| 价格 | 17–36px | 800–850 | 金额 |

## 4. 布局与间距

- 设计基准：390 × 844（iPhone 13/14 尺寸），移动端全屏。
- 桌面：手机壳预览 + 左侧品牌介绍 + 右侧演示控制，宽度自适应；手机壳在 1440×900 下缩放为 358×780。
- 页面安全区：状态栏 44px（仅桌面手机壳内显示）、Nav 48px、TabBar 58px + safe area。
- 内容边距：页面 14px；卡片内 13–15px；卡片间距 9–10px。
- 圆角：卡片 15–18px，按钮 10–12px，标签 5–7px，头像圆形。
- 阴影：轻量、低对比；不使用霓虹/玻璃拟态作为主要视觉。

## 5. 组件

### 导航
- 顶部 NavBar：返回 + 标题 + 右侧操作；吸顶、白底、细分割线。
- 底部 TabBar：首页 / 订单 / 我的，3 项；未读/待付款显示小圆点；未登录时不显示账户徽标。
- 首页头部：珊瑚红渐变、城市、搜索、服务保障条；大圆角底部与页面衔接。

### 卡片
- 服务卡：左侧插画 + 标题/副标题/标签/价格/销量。
- 分类卡：2 列，第 5 个跨 2 列；浅色底 + 圆形箭头 + 插画。
- 师傅卡：头像 + 认证徽标 + 姓名/等级 + 评分/接单/好评 + 标签/可约时间 + 选择按钮。
- 订单卡：状态标签 + 订单号 + 服务/时间/师傅 + 实付 + 1–2 个操作。
- 优惠券卡：左侧面额区、虚线缺口、右侧信息与状态。

### 表单
- 行式「标签 + 输入」结构，底部细线；获得焦点时边框/底线变珊瑚红。
- 手机号支持 `138 0013 8000` 格式化显示，内部存 11 位数字。
- 验证码区域：输入 + 获取/验证按钮 + 演示提示；验证成功显示绿色勾选。
- 地址标签：家 / 公司 / 父母家 / 其他；默认地址唯一。
- 日期卡片 + 时段网格；过期时段置灰并显示「已过」。
- 协议勾选使用圆形 checkbox；协议链接独立于 checkbox，避免嵌套按钮。

### 弹层
- 底部 Sheet：白色、22px 顶部圆角、拖拽条、标题 + 关闭、滚动 body、固定 footer。
- 居中 Dialog：确认/登录/重置等短决策。
- 全屏协议抽屉、授权弹窗、定位弹窗。
- 所有页面级弹层通过 portal 挂载到手机屏幕的 overlay root，避免长页面滚动导致弹层错位。

### 反馈
- Toast：单条、2.4 秒、深色底；成功/错误/信息图标 + 颜色。
- 空状态：插画 + 标题 + 说明 + 主行动。
- 加载：Spinner；支付中、定位中、授权中。
- 动效：150–300ms，GPU 属性；尊重 `prefers-reduced-motion`。

## 6. 插画与图标

- 5 个服务插画：沙发、窗帘、地毯、床垫、空调；统一 200×160 viewBox、浅色底、气泡/光点、圆润形状。
- 师傅头像：原创矢量人物，6 个种子/配色，不同发型与肤色；白色衣领 + 薄荷制服。
- 用户头像：文字首字 + 渐变圆；未登录为用户轮廓图标。
- 图标：手绘 24×24 线条 SVG，1.8px 描边，圆角端点；不依赖图标字体/CDN。
- 无外部图片、无占位图 URL、无 emoji。

## 7. 页面结构原则

1. **一眼看到状态**：订单详情顶部即为状态与下一步说明。
2. **一个主行动**：每个页面底部最多一个主按钮；次操作使用 ghost/outline 或文字链。
3. **可返回、可恢复**：表单与草稿持久化；协议用弹层打开，不丢表单。
4. **可信信息前置**：服务保障、师傅资质、价格构成、取消规则在决策点可见。
5. **演示数据可识别**：演示控制、固定验证码、模拟支付均有明确提示。

## 8. 响应式

- < 920px：全屏 App，隐藏手机壳、桌面侧栏与状态栏。
- 920–1180px：保留手机壳与左侧介绍，隐藏右侧演示控制。
- > 1180px：完整三栏展示。
- 高度不足 960px：手机壳缩放至 358×780；高度不足 820px：进一步缩小并隐藏部分介绍步骤。
- 所有交互目标 ≥ 36–44px；主要按钮 44–46px。

## 9. 无障碍

- 图标按钮均带 `aria-label`；Tab / Dialog / Sheet 有 role 与 aria 属性。
- 表单字段具备 label / aria-label；错误信息以文字显示。
- 支持键盘 Esc 关闭弹层；焦点环使用 `outline`。
- 颜色不作为唯一状态表达：状态同时有文字/图标。
- 尊重 `prefers-reduced-motion`。
