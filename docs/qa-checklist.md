## 2. 端到端场景

### 2.1 主链路（`scripts/flow.mjs`）

- 首页 → 空调清洗 → 空调挂机全拆深洗
- 切换 2 匹规格；选择陈建国师傅
- 确认订单 → 获取手机号（模拟授权）→ 校验通过
- 勾选协议 → 提交 → 收银台 → 微信支付确认 → 支付成功
- 等待 8 秒自动接单 → 查看订单 → 待服务
- 演示控制推进：师傅已出发 → 服务中 → 确认服务完成 → 待评价
- 评价 5 星 + 标签 + 文字 → 已完成，5 元券到账
- 我的/订单列表数据回流

结果：**通过**，订单数据正确持久化，无页面报错。

## 4. 已覆盖的边界

- 手机号：空、位数不足、非法号段、修改后重新验证、验证码错误/正确
- 地址：选择、切换、新增、默认、删除（二次确认）
- 日期：过期为灰、今日仅剩可用时段、未来 7 天
- 金额：规格 × 数量、优惠券门槛/范围、优惠后合计、取消退款估算
- 订单：待付款、待接单、待服务、已出发、服务中、待评价、已完成、已取消
- 账号：未登录、微信登录（无手机号）、手机号登录、手机号授权、退出
- 弹层：长页面滚动后打开弹层仍居中/贴底（portal 修复）
- 状态：自动接单定时器、演示推进、评价回流

## 5. 已知限制

- 无后端；自动接单、状态推进均为前端定时器/演示按钮。
- 支付、短信、定位、分享、相册、发票均为模拟。
- 真实浏览器权限可能影响“获取手机号/定位”的演示，故使用明确标注的模拟弹层。
- 演示二维码小程序能力（`getPhoneNumber` 等）不代表真实微信授权。
