# 天鹅到家调研摘要与产品取舍

> 调研时间：2026 年 11 月。以下内容来自公开资料与产品形态观察，仅用于内部演示设计参考，不代表天鹅到家官方信息或完整产品能力。

## 1. 产品与渠道

天鹅到家（原 58 到家）是家庭服务平台，公开资料显示其覆盖全国 300+ 城市，业务包括保洁、家电清洗、保姆、月嫂、育儿嫂、搬家、维修等。服务入口包括：

- **天鹅到家 APP**：主产品，含客户端与师傅/商家端。
- **微信小程序**：「天鹅到家保洁」等，承担轻量浏览、预约与支付。
- **H5 / 官网**：城市站、服务列表与协议公示页面，例如 `bj.daojia.com`。
- **客服与售后**：APP 内在线客服、电话、订单售后入口。

本次设计以「客户端清洗预约」为主，参考小程序与 APP 的共性结构，不实现师傅端、商家端与后台。

## 2. 能力地图（客户端）

| 模块 | 关键能力 | 对本次演示的启发 |

| 预约下单 | 地址、服务时间、规格/数量、备注、优惠券、协议 | 确认订单页、地址簿、日期/时段、优惠券、协议勾选 |

## 3. 典型下单链路

综合公开的小程序操作指引与流程资料，清洗类预约通常为：

```
打开小程序 / APP
→ 定位城市 / 选择城市
→ 首页选择服务分类（日常保洁 / 家电清洗 / 专项清洗）
→ 服务列表选择具体服务
→ 服务详情查看价格、规格、评价、保障
→ 选择购买规格 / 数量
→ 选择服务地址
→ 选择服务日期与时段
→ 填写联系人 / 手机号（可授权本机号码）
→ 领取或选择优惠券
→ 阅读并同意服务协议
→ 提交订单 → 支付
→ 等待师傅接单 / 平台派单
→ 师傅上门 → 服务完成
→ 评价 / 售后
```

与「天鹅到家」传统保洁不同，清洗类服务更偏「按件/按面积/按规格」定价，并带有明确的拆洗范围和设备要求；师傅/服务商的展示与指定也比保姆类更轻量。因此本演示：

- 不设置服务时长选择（清洗按规格与服务量计价），保留服务时长展示；
- 强化「规格 + 数量」与「拆洗范围」；
- 提供指定师傅/平台优选两种方式；
- 保留地址、时间、手机号、优惠券、协议等下单必备项。

## 4. 清洗类服务与定价参考

公开市场信息与平台页面显示，清洗类服务通常按以下方式计价：

- **沙发**：按单人/双人/三人/转角位、布艺/真皮、是否除螨区分；
- **窗帘**：按片计费，常见 2 片起订；区分纱帘/布帘/遮光帘，免拆/拆装；
- **地毯**：按面积（㎡）或按张，区分羊毛/普通/满铺；
- **床垫**：按尺寸（1.5m/1.8m/2.0m）、单双人、婴儿床垫；
- **空调**：按挂机/柜机/中央空调风口、匹数、台数计价；深度清洗通常包含外壳、滤网、蒸发器、风轮、排水检查；
- 市场参考价（2026 年公开报道）：挂机深度清洗约 100–180 元/台，柜机约 150–220 元/台；本演示采用 119/139/159 元等价格，仅作演示，不是官方报价。

本演示的服务规格与价格：

| 分类 | 服务数 | 价格区间（演示） |
|---|---|---|
| 沙发清洗 | 3 | ¥69–¥249 |
| 窗帘清洗 | 2 | ¥49–¥109 / 片 |
| 地毯清洗 | 3 | ¥139–¥319 / 张，办公 ¥199–¥599 |
| 床垫清洗 | 3 | ¥89–¥179 / 张 |
| 空调清洗 | 4 | ¥99–¥309（挂机/柜机/中央空调/套餐） |

## 5. 订单与售后规则

### 公开信息观察

- 天鹅到家公开协议/帮助内容强调：平台提供信息与交易服务，服务者需实名认证、健康证明与技能培训；订单可查看服务者信息、评价与售后进度。
- 取消规则通常表述为「未到服务时间，可在待服务订单中取消；是否扣费以订单详情页取消扣款说明为准」，套餐预约取消后剩余次数退回套餐。
- 售后包括返工、退款、保险理赔与客服介入；部分订单含人身/财产保障。
- 平台协议与服务协议区分「平台服务」与「具体清洗服务」，并把取消、退款、责任限制写在协议中。

### 本演示采用的简化规则

为了演示可解释、可操作，采用以下规则（并非真实平台规则）：

| 场景 | 处理 |
|---|---|
| 待付款取消 | 无扣款 |
| 距服务开始 > 4 小时 | 全额退款，优惠券退回 |
| 距服务开始 ≤ 4 小时 | 扣 20%，单笔最高 50 元 |
| 师傅已出发 | 扣 30%，单笔最高 80 元 |
| 服务开始后 | 不可直接取消，引导客服 |
| 师傅迟到 > 30 分钟 | 可免费取消（协议中说明） |
| 评价完成 | 发放 5 元无门槛券（演示） |

### 协议体系

演示包含 6 份协议，结构参考行业公开规则：

1. 用户协议：账号、下单、支付、行为规范、责任限制、协议变更；
2. 隐私政策：手机号、地址、位置、订单信息、共享范围、用户权利；
3. 平台服务协议：平台角色、师傅管理、费用结算、评价与争议；
4. 清洗服务协议：服务范围、上门规范、验收标准、物品损坏、安全配合；
5. 取消与退款规则：时间分档、退款路径、优惠券退回；
6. 服务保障说明：四重保障、返工、损坏处理、售后入口。

所有协议均为演示文本，详见 `src/data/agreements.ts`。

## 6. 视觉与交互观察

- 官方站点主色偏珊瑚红（CSS 中高频出现 `#ff4d4c`、`#ff544f`、`#24324a` 等），小程序「天鹅到家保洁」的服务卡片使用薄荷绿/青色作为分类辅色，价格用红色强调；
- 首页通常为：城市/定位、搜索、Banner、服务分类、服务保障、推荐服务/师傅、内容与 FAQ；
- 服务详情：价格、规格、优惠券、评价、图文详情、底部购买栏；
- 我的：头像/手机号、订单状态入口、地址、优惠券、客服、协议；
- 订单状态强调「待服务/服务中/待评价」，并提供联系师傅、改期、取消、售后；
- 移动端底部 Tab 通常为「首页 / 订单 / 我的」。

本演示在此基础上做了统一：珊瑚红主色 + 薄荷绿辅色 + 暖白底、圆角卡片、插画化服务分类、手机壳桌面预览与演示控制侧栏。

## 7. 吸收与取舍

### 吸收

- 分类 → 详情 → 规格/数量 → 地址/时间 → 手机号 → 支付 → 接单 → 服务 → 评价的主链路；
- 师傅档案、评分、接单量、认证标签、指定/平台优选；
- 多地址、城市定位、手机号授权、优惠券、协议、取消退款；
- 订单状态与时间线、售后、客服；
- 首页服务保障与 FAQ 的信任建设。

### 主动简化 / 排除

- 不实现保姆/月嫂/育儿嫂、搬家、维修等非清洗类目；
- 不实现师傅端、商家端、后台审核、结算、保险理赔、发票；
- 不做真实 LBS 地图、路线与派单算法；
- 不做真实短信、微信登录/支付、实名认证；
- 不做真实照片上传与清洗前后对比图；
- 价格、师傅、评价、协议均为前端模拟数据。
